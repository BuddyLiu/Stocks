# AI 巴菲特炒股助手 — 投资策略说明书

> 本策略参照沃伦·巴菲特的价值投资经验整理，由**确定性量化引擎**与 **Claude 语义分析**两部分组成：量化引擎负责可解释、可复现的财务质量评分与估值；Claude 负责护城河、管理层、能力圈等难以量化的定性判断。**量化结论由规则引擎决定，AI 只解释、不覆盖。**

---

## 1. 巴菲特的核心理念

### 1.1 以合理价格买入伟大公司并长期持有
> "我们最喜欢的持有期是永远。"

巴菲特的投资不是"买便宜的"，而是"买伟大的、并长期拿着"。因此本助手不追求短期波段，评分体系聚焦**公司质量**而非**短期动量**。

### 1.2 七条原则（对应本系统的判断依据）

| # | 原则 | 含义 | 在本系统中的落地 |
|---|---|---|---|
| 1 | **能力圈** | 只投资能理解商业模式的公司 | Claude 评估"商业模式可理解性"；看不懂的不投 |
| 2 | **经济护城河** | 持久竞争优势（品牌/网络效应/转换成本/成本优势/无形资产/有效规模） | Claude 判断护城河类型与持久性 |
| 3 | **财务质量** | 高且稳定的 ROE、高利润率、低负债、盈利稳定、强自由现金流、轻资产 | 量化引擎「财务质量」「资产负债表」维度 |
| 4 | **内在价值与安全边际** | 买价须显著低于保守估算的内在价值 | DCF 内在价值 + 安全边际要求 ≥25–30% |
| 5 | **市场先生** | 市场报价只是参考，要利用波动而非被其左右 | 系统用"现价 vs 内在价值"，而非追涨杀跌 |
| 6 | **集中与长期持有** | 少而精、有耐心、不频繁交易 | 结论为「买入区间」才考虑建仓，默认长期持有 |
| 7 | **不加杠杆** | 避免借贷投资 | 报告中单列杠杆风险提示；组合层面给出仓位建议 |

## 2. 量化评分体系（0–100 分）

对每一只股票，从 5 个维度打分，加权合成总分。**每个指标都是公开财务数据、可复现。**

| 维度 | 权重 | 子指标 | 满分标准 |
|---|---|---|---|
| **财务质量** | 25% | 近 5 年平均 ROE ≥ 15% 且逐年稳定（标准差小） | 高质量盈利 |
| | | 净利率 ≥ 15%，且稳定 | 强定价权 |
| **资产负债表** | 20% | 美股 D/E < 1；A股 资产负债率 < 60%（**金融股豁免**，用权益质量替代） | 低杠杆 |
| | | 利息保障倍数 ≥ 5 | 付息无忧 |
| **盈利稳定与增长** | 20% | 可用历史**无亏损年**（目标 10 年，至少 5 年） | 可预测性 |
| | | EPS 正增长年占比 ≥ 2/3，复合增速为正 | 持续成长 |
| **现金流** | 15% | 自由现金流多数年份为正 | 真金白银 |
| | | FCF / 净利润 ≥ 0.7 | 盈利质量高 |
| | | 轻资产（高 ROIC / FCF 率） | 少资本再投入 |
| **估值与安全边际** | 20% | PE / PEG / PB 相对历史与同业合理 | 价格不贵 |
| | | **DCF 安全边际**（见 §3） | 打折买入 |

> 数据覆盖不足的处理：A股 10 年、美股 FMP 免费档仅 5 年。**「盈利稳定与增长」得分按实际覆盖年数缩放**，并在报告中标注"数据覆盖 5 年"的局限，避免因数据不足误判。

### 2.1 结论判定（确定性规则）

| 结论 | 触发条件 |
|---|---|
| 🟢 **买入区间** | 安全边际 ≥ 30% 且 总分 ≥ 70；或 总分 ≥ 75 且 安全边际 ≥ 25% |
| 🟡 **观望** | 0 < 安全边际 < 25–30%；或 60 ≤ 总分 < 70 |
| 🔴 **回避** | 安全边际 ≤ 0；或 总分 < 50；或 出现红旗（负净资产 / 存在亏损年 / FCF 持续为负） |

「买入区间」意味着**可分批建仓**，而非一把梭；「观望」意味着"好公司，但要等更好的价格"。

## 3. DCF 内在价值（简化两阶段模型）

巴菲特不给出精确公式，但"公司价值 = 未来自由现金流的折现"是其底层逻辑。本系统采用**保守口径**：

```
g = min(近 5 年 FCF 复合增速, 8%)     // 增长保守封顶 8%
折现率 r = 10%                        // 无风险利率 + 股权风险溢价
永续增长率 = 2.5%

IV = Σ( t=1..10 ) FCF·(1+g)^t / (1.10)^t
   + TV / (1.10)^10
   + 净现金 (现金 − 有息负债)

TV = FCF·(1+g)^10 · (1+2.5%) / (10% − 2.5%)
IV/股 = IV ÷ 总股本
安全边际 = (IV/股 − 现价) / IV/股
```

要点：
- 增长上限 8% 体现巴菲特"不预测高增长"的保守；
- A股 需扣除少数股东权益，用归母口径；
- 当 FCF 为负或数据缺失时，安全边际直接判为不成立（回避），绝不硬算。

## 4. Claude 定性分析框架

量化引擎输出结构化指标与评分后，交由 Claude 完成三件事（**均不改变量化结论，只提供解释与深度**）：

### 4.1 护城河评估
- 护城河类型：无形资产 / 转换成本 / 网络效应 / 成本优势 / 有效规模
- **强度**：宽 / 窄 / 无 三级 + 佐证（如毛利率水平、市占率稳定性）
- 持久性：未来 10 年能否维持

### 4.2 管理层质量
- 资本配置：再投资回报、分红/回购是否股东友好
- 诚实与理性：有无会计激进迹象、关联交易、频繁变更主业
- 激励是否与股东利益一致

### 4.3 能力圈与商业模式
- 商业模式是否简单可理解
- 未来 10 年能否预见经营走向

### 4.4 输出形式
- 结构化字段 + 一段自然语言中文「巴菲特健康报告」（Markdown，App 内渲染）
- 报告 = 量化引擎的分项得分与结论（直接渲染）**+** Claude 的护城河/管理层叙事

## 5. 组合层面纪律（自选 / 持仓视图）

1. **集中但不过度**：单票占组合比例建议 ≤ 组合的 30%（自选配置中提示）
2. **整体健康度**：组合加权 ROE、平均安全边际、持仓总体结论分布
3. **长期持有**：除非基本面恶化（评分跌破回避线）或安全边际显著收窄，否则不建议卖出
4. **不加杠杆**：持仓视图中对"成本高于内在价值"的仓位给出风险提示
